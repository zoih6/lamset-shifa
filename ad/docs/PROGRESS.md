## كيف تكمل من الصفر
1. `bash <(curl -fsSL https://raw.githubusercontent.com/zoih6/motion-doc-studio/main/install.sh)`
2. `cd ad && ln -sfn ~/.motion-doc-studio/node_modules node_modules`
3. `cd film && PAGE=index.html node ../tools/still.mjs <t1> <t2> …` للمراجعة
4. `PAGE=index.html node ../tools/render.mjs --from 0 --to 61.6 --out /tmp/silent.mp4 --sub 2 --crf 18`
5. دمج الصوت: `ffmpeg -i /tmp/silent.mp4 -i ../../assets/../VID-*.aac -map 0:v -map 1:a -af volume=-1.6dB -c:v copy -c:a aac -b:a 192k -shortest final.mp4`
